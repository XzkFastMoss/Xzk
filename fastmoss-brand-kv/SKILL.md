# FastMoss Brand KV

Produce market-ready FastMoss visuals that are recognizable, product-clear, and channel-appropriate. Treat bundled assets as source layers; never redraw the logo or bake important Chinese copy into generated imagery.

## Route the task

1. Identify the output type, channel, dimensions, audience, campaign, primary message, CTA, language, and delivery format.
2. If the brief omits non-critical details, use the defaults below and state them in the handoff. Ask only when a missing choice would materially change the result.
3. Read the required references:
   - Always read [brand-system.md](references/brand-system.md).
   - Read [product-messaging.md](references/product-messaging.md) for any external-facing copy.
   - Read [material-recipes.md](references/material-recipes.md) for the requested format or channel.
   - Read [creative-poster-guide.md](references/creative-poster-guide.md) for posters, campaign KVs, social covers, event graphics, or any brief asking for a stronger concept, composition, visual hook, or creative direction.
   - Read [quality-checklist.md](references/quality-checklist.md) before delivery.
4. Inspect relevant files in `assets/` visually before composing. Use [asset-manifest.md](references/asset-manifest.md) to choose them.

## Default brief

Use these defaults only when the user does not specify them:

- Audience: TikTok merchants, brands, agencies, and cross-border e-commerce operators.
- Goal: explain what FastMoss does before promoting an event or offer.
- Tone: professional, energetic, data-driven, internationally minded.
- Primary message: FastMoss is a TikTok e-commerce data analysis and growth decision platform.
- Visual mode: white or warm-white product canvas with pink decorative light, purple secondary accents, and one product-led focal point.
- CTA: `做 TikTok，就用 FastMoss` unless a campaign-specific CTA is supplied.
- Promotional intensity: light. Do not introduce discounts, prices, or superlative claims without an explicit, verified brief.

## Build the message hierarchy

Keep one dominant idea per visual:

1. **Brand anchor:** place the exact FastMoss logo in a stable, high-contrast area.
2. **Primary headline:** communicate the campaign idea or product benefit in no more than two short lines when possible.
3. **Product explanation:** state what FastMoss helps users do. New audiences must understand the category without relying on the caption.
4. **Proof or feature block:** show either the four core capabilities or the four data proof points; avoid forcing both into a small canvas.
5. **CTA/campaign mark:** keep subordinate to the headline.

For product-awareness materials, prefer this sequence:

`FastMoss 是什么 → 四大核心功能 → 数据证明 → AI/Agent 能力 → CTA`

For a single static KV, compress the sequence into:

`产品定位 + 1 个核心利益点 + 1 组证明 + CTA`

## Develop the creative concept

For posters, covers, and static campaign KVs, define the concept before styling:

1. Write one real merchant question or tension the visual addresses.
2. Choose one visual metaphor that makes the idea visible.
3. Write one concrete point of view rather than using a feature name as the headline.
4. Select one product proof: an authorized interface, approved number, result structure, or workflow.
5. Choose one action the audience should take.

Use this formula:

`真实问题 + 视觉隐喻 + 明确观点 + 产品证据 + 行动入口`

Select one dominant visual only. Build a three-level hierarchy: first-glance brand/headline/hero, second-glance explanation/proof, and third-glance CTA/details. Make the headline and hero explain each other. Read [creative-poster-guide.md](references/creative-poster-guide.md) for composition patterns, FastMoss adaptations, examples, and anti-patterns.

## Compose the visual

- Establish a clear reading path: logo → headline → hero visual/product UI → proof → CTA.
- Use an asymmetric composition with generous negative space. Let one oversized KV object, number, data form, or interface crop carry the visual.
- Use white or warm white as the full-canvas base, FastMoss pink as the action and emphasis color, purple as depth, and slate only for text or a small local highlight panel.
- Keep backgrounds light. Never use `#10111A`, black, charcoal, or another dark color as a full-canvas background. A dark slate card may occupy a small local area when it improves hierarchy, as in the V3 product-function reference.
- Build decoration from pale pink radial washes, translucent rose shapes, fine pink/purple grid lines, cropped brand assets, and a thin pink-to-purple edge rule. Preserve generous white space.
- Keep interface screenshots legible and purposeful. Crop to the feature being explained; do not use them as generic texture.
- Preserve all text as editable vector/code-native layers where possible.
- When using generative imagery, generate only decorative backgrounds, abstract data environments, or supporting objects. Composite the exact logo, Chinese text, product UI, and numbers afterward.
- Do not imitate TikTok branding or imply platform endorsement. Mention TikTok only as the product's market domain.

## Select the production method

- Raster poster, cover, or ad: use a code-native canvas/vector workflow for typography and logo; use image generation only for supporting art if needed.
- Motion KV or social video: invoke the available Remotion skills, keep the logo fixed when requested, and inspect representative frames before rendering.
- Web hero or landing section: invoke the available frontend/Sites skill and use responsive SVG/image layers.
- Presentation cover or sales visual: invoke the presentation skill and preserve editability.
- Multi-account variants: make substantive differences in headline, hook, composition, crop, reading order, and motion; do not rely on mirroring, filters, speed changes, or tiny color adjustments.

## Produce variants deliberately

When alternatives are requested, create named creative territories rather than near-duplicates:

- **Data Intelligence:** white data canvas, pink grid, chart, globe, and structured proof.
- **AI Workflow:** white product canvas, Agent prompt, connected modules, and soft rose-purple light.
- **Growth Discovery:** white editorial canvas, directional motion, creator/content nodes, and pink opportunity signals.
- **Anniversary Brand:** white campaign canvas, hero `4`, celebratory ribbon, and restrained member-month message.

Keep immutable brand facts identical across variants: logo geometry, approved product claims, data labels, and official feature names.

## Verify and deliver

1. Render at the exact target dimensions.
2. Inspect the full canvas and at least one small-scale preview representing feed visibility.
3. Run every item in [quality-checklist.md](references/quality-checklist.md).
4. Confirm spelling, numbers, product meaning, logo integrity, safe margins, contrast, and asset authorization.
5. Deliver the editable source plus final export when the format supports both.
6. Summarize the creative direction, dimensions, included claims, and any assumptions.

Never claim guaranteed platform approval, performance, conversion, or originality status.
